# TheGopher

A personal collection of Go side projects and experiments. This repository serves as a workspace for backend development, exploring different architectures, and refining the Go programming skills.

## Projects Included

- **[GoAuth](./GoAuth/)**: A secure user authentication and management service using an in-memory thread-safe store.
- **[GoLibre](./GoLibre/)**: A library management system demonstrating MongoDB integration and robust configuration management.
- **[GoSync](./GoSync/)**: A user synchronization service implementing a Layered Architecture (Controller-Service-Data) with MongoDB.
- **[GoTaskit](./GoTaskit/)**: A clean, efficient Task Management REST API using an in-memory store and Gin framework.

## Goals

- **Learning**: Testing different design patterns (Layered Architecture, Dependency Injection).
- **Best Practices**: Implementing clean code, structured logging, and proper error handling.
- **Experimentation**: Trying out different storage strategies (In-Memory vs. MongoDB).
